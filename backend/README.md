# AI Scheduler Backend

Node.js API for storing users and scheduler tasks in MongoDB and generating task portions with Gemini.

## Setup

1. Create `backend/.env` from `.env.example`.
2. Set `MONGO_URI` and `JWT_SECRET`. `GEMINI_API_KEY` and SMTP credentials are optional.
3. Install dependencies:

```bash
npm install
```

4. Check MongoDB configuration:

```bash
npm run check
```

5. Start the API:

```bash
npm run dev
```

The server connects to MongoDB before starting. MongoDB creates the collections when users or tasks are first saved.

When `GEMINI_API_KEY` is set, task schedules are generated by Gemini. Without a key, the API uses its built-in local fallback planner and does not contact Gemini.

In development, the frontend proxies `/api` requests to `http://localhost:5000`.

Email reminders are checked every minute. When a task portion reaches its
scheduled start time, the backend sends the enabled email notification.

Email uses Nodemailer with SMTP, so it can work for free with an email account
you already have. For Gmail, use an app password as `EMAIL_PASS`.

## Endpoints

- `GET /api/health`
- `POST /api/auth/signup` with `{ "name", "email", "password" }`
- `POST /api/auth/login` with `{ "email", "password" }`
- `GET /api/tasks`
- `POST /api/tasks`
- `PATCH /api/tasks/:id/status`
